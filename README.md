## 📖 About

This is a **single‑page static website** for a fictional "Rent‑a‑Girlfriend / Bestie / Cuddler / Sister" service.  
It’s designed to combat the loneliness epidemic by offering genuine, platonic, and sacred companionship – just for a few hours, with zero strings attached.

**Visually**, it’s a love‑letter to the Y2K era: bubblegum pink (`#ff7bb5`), toxic lime (`#d9fb5f`), chunky Windows‑style windows, glitter animations, scanline overlays, zebra/cheetah print textures, and a floating chrome sphere.

---

## ✨ Features

- 🖥️ **Y2K Aesthetic** – Skeuomorphic windows, pixel fonts, glitter, and retro overlays.
- 💬 **4 Service Tiers** – Girlfriend, Girl‑Bestie, Cuddler, and Sister – each with clear *included* / *excluded* lists.
- ✉️ **Working Enquiry Form** – Submissions sent straight to your email via **Formspree**.
- 🚀 **Modern CI/CD** – Deployed automatically to GitHub Pages using **GitHub Actions** (no manual `gh-pages` branch juggling).
- ⚡ **Lightning Fast** – Built with Vite; globally cached via Fastly CDN.
